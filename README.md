# 🎬 Netflix Dataset Analysis (Python Project)

## 📘 Overview
This project analyzes a Netflix dataset to uncover key insights about the platform’s content — including **Movies vs TV Shows distribution**, **top countries**, **popular genres**, and **trends over time**.

The analysis was done using Python libraries like **Pandas, Matplotlib, and Seaborn** in Jupyter Notebook.

---

## 📊 Dataset Information

**File:** `Netflix_Dataset.xlsx`  
**Rows:** 100  
**Columns:**
- `show_id`: Unique ID for each title  
- `type`: Movie or TV Show  
- `title`: Title name  
- `director`: Director name  
- `cast`: Main actors/actresses  
- `country`: Country of origin  
- `date_added`: Date added to Netflix  
- `release_year`: Year of release  
- `rating`: Content rating (TV-MA, PG, etc.)  
- `duration`: Duration in minutes or seasons  
- `listed_in`: Genre/category  
- `description`: Short summary  

---

## 🧠 Objectives

1. Analyze the distribution of Movies vs TV Shows  
2. Identify top content-producing countries  
3. Visualize content addition trends over time  
4. Discover the most common genres  
5. List top directors on Netflix  
6. Analyze ratings and type distribution  

---

## 🛠️ Libraries Used

- **Pandas** → Data Cleaning & Manipulation  
- **NumPy** → Numerical Operations  
- **Matplotlib** → Basic Visualization  
- **Seaborn** → Advanced Visualizations & Styling  

---

## 📈 Key Visuals

1. **Movies vs TV Shows Distribution**
   - Countplot showing Netflix’s content split.

2. **Top 10 Countries**
   - Bar chart showing which countries produce the most content.

3. **Content Added Over the Years**
   - Line plot showing how Netflix’s library has grown over time.

4. **Top 10 Genres**
   - Bar chart showing which genres dominate the platform.

5. **Top 10 Directors**
   - Visualization of directors with the most titles.

6. **Ratings Distribution**
   - Countplot comparing ratings between Movies and TV Shows.

---

## 🔍 Insights Summary

- **Movies dominate** Netflix’s catalog compared to TV Shows.  
- **United States, India, and UK** lead in content production.  
- A major **content surge occurred after 2015**, matching Netflix’s global expansion.  
- **Drama, Comedy, and Action** are the most popular genres.  
- **Top directors** often specialize in specific genres or countries.
